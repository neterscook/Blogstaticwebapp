This is code for a static web builder, once launched it allows the user to customize and then export a web-page html file. 

Blocks: on each page you can add blocks including
        - hero/header text
        - Navigation bar
        - Regular text
        - Images
        - 2 and 3 column tables
        - Card
        - Quote
        - Divider
        - Spacer
        - Footer
        - Postcard-style grid
        - Tabbed menu
        - Photo grid + captions
        
Themes: You can customize the theme of the site 
  - Background Color  
  - Text Color
  - Font Family
  - Content Width   
  - Font Size
  - Line Height
  - Page Padding

Pages: You can add multiple pages/content tabs to the site
